# FY Squad MB 项目规则

## 腾讯云配置

- **SecretId**: 从环境变量 TENCENT_SECRET_ID 读取
- **SecretKey**: 从环境变量 TENCENT_SECRET_KEY 读取
- **注意**: 敏感信息已移至环境变量，请勿硬编码

## 基础规则

- **中文优先**: 用户不精通英文，所有脚本输出、日志、交互界面及代码注释必须使用**中文**。
- **代码规范**: 注释使用中文，保持代码风格一致。
- **自动化执行**: 不要让用户手动操作开发、部署等操作，用户不会开发，所有操作需由我自动完成。

## 文件编码

- **Windows 脚本**: BAT/CMD 建议使用 **GB2312** 编码，防止中文乱码。
- **PowerShell**: 需确保编码兼容性。
- **编码转换**: 涉及 Windows 系统交互时，务必严格处理编码转换，避免乱码导致的执行错误。

## 环境要求

- **运行环境**: 脚本将在 Windows 系统上运行。
- **权限要求**: 脚本通常需要 **管理员权限** 运行。
- **本地环境**: Trae 安装在本地。
- **远程服务器**: 目标服务器为上述腾讯云服务器（43.138.188.183）。

## 操作规范

- **SSH 优先**: 能通过 SSH 解决的问题，建议通过 SSH 远程解决，而不是手动操作服务器。
- **临时文件**: 脚本生成的临时配置文件或中间产物，使用后必须及时删除。
- **自动化监控**: 需要我自己监控终端，让用户无需在终端输入任何命令。
- **服务器操作标准化**: 所有服务器操作必须遵循 [server-operation-rules.md](.trae/rules/server-operation-rules.md) 中的规范，包括：
  - 操作类型分类（配置修改、服务启停、数据备份等）
  - SSH 与腾讯云 API 的适用场景定义
  - 鉴权机制、请求格式及错误处理
  - 操作审计与日志记录要求
  - 操作冲突处理机制
